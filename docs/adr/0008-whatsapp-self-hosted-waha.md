# WhatsApp can run through a self-hosted WAHA gateway, with Chatmaid kept as a fallback

Residio adds a fourth WhatsApp provider, `waha`: the open-source WAHA gateway (`devlikeapro/waha`, NOWEB engine, Apache-2.0) run as its own Coolify application beside Residio (#1260). It sits in the provider registry from ADR-0003 like the others: one active provider at a time, credentials encrypted in `whatsapp_provider_credentials`, a send adapter (`src/lib/whatsapp/providers/waha.ts`) and its own inbound route (`/api/whatsapp/webhook/waha`, HMAC-SHA512 over the raw body).

Why: each existing provider has a cost the owner wants to remove. Chatmaid, the WhatsApp Web bridge added in #401, is unstable (#1076, #839, #842, #941). Meta needs business verification and approved templates. Twilio adds a per-message fee. WAHA gives the Chatmaid model (a QR-paired phone, free text, media by URL) without a third party in the path: it has an API key, a QR dashboard, signed webhooks with retries, and a message store the reconciliation cron (`whatsapp-waha-reconcile`) can read back, so a missed webhook is recovered rather than lost.

Why not the repository the owner first asked about (`navneetyadav-code/whatsapp-api`, reviewed 27 Oct 2026): it was three weeks old with one author, ran PHP, Node and MySQL in one root container, had no real tests in CI, and fixed phone numbers to India. Its only useful part was the Baileys library, which WAHA's NOWEB engine already uses. Other gateways were surveyed (#1260); GOWA is the strongest alternative and the switch would be another adapter, not a redesign.

Risk accepted: WAHA, like Chatmaid, uses the unofficial WhatsApp Web protocol, which Meta's terms do not permit, so the estate number can be banned. The send policy (daily cap, burst cap, opt-in only) stays on to keep the number's behaviour ordinary. Chatmaid stays a selectable provider, so the estate can switch back from **Settings > WhatsApp** without a deploy if WAHA fails. Prod, `@lid` sender resolution and putting the WAHA dashboard behind Cloudflare Access are later work.
