# WhatsApp Assistant is a deliberate resident-facing surface despite the admin-first guardrail

`AGENTS.md` states all forward work targets the admin dashboard and that resident self-service is not scheduled for rollout. The WhatsApp Assistant is explicitly an exception: a resident-facing WhatsApp surface delivering estate reminders/announcements (admin value: better collections and estate communication) and structured financial self-service (the adoption hook for the channel). We decided in grill session Q1 to treat this as a deliberate new bet rather than deferring it to the portal's (un)scheduled timeline. The web-resident-portal guardrail itself is unchanged — only the WhatsApp surface is exempt, and only for what this module covers (identity, opt-in, PIN, community tier, financial menu). Portals remain out of scope.
