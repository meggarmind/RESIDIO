# Exceptions

Owner-granted waivers. A page listed here for a check is recorded as `waived` in an audit, not
`fail`. An exception is granted only by the owner, in writing, on an issue or on #412. An agent may
propose one in a PR description; it never adds a row on its own.

Each row needs every column. A row with a blank reason or decision link is invalid and is treated
as absent.

| Check | Page (route) | Reason | Decision | Granted |
| --- | --- | --- | --- | --- |
| | | | | |

## How to propose one

1. State the check id, the route, and why the rule does not serve the officer on this page.
2. Name the alternative that does serve them.
3. Put it in the PR description under "Proposed exception". Do not edit this file.
4. When the owner agrees, they or the coordinator add the row with the issue or comment link and
   the date.

## Retired exceptions

When the page changes so that the rule applies again, move the row here with the date and the
change that made it apply.
