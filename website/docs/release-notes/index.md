# Release notes

Each Residio release has one page. The page tells you what is new and what changed. It does not
tell you how the code changed.

The release type tells you how much changed:

- **Major**: upgrade steps are necessary. Read "Before you upgrade" on the page first.
- **Minor**: the release adds features. No upgrade steps are necessary.
- **Patch**: the release fixes problems only.

The newest release is at the top of the table.
