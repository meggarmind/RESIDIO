# Release v1.10.0

**Release date:** 22 October 2026. **Release type:** Minor (new features, no upgrade steps).

## Summary

Super admins can now merge two records of one resident into one. Admins can use WhatsApp to check what a house owes and to get a debt status report. Two-factor login is now complete. This release also fixes several billing, payment and messaging problems.

## New features

### Residents

- A super admin can merge a duplicate resident into the resident to keep. The **Merge residents** button is on the resident detail page.
- The dialog shows a preview of what moves: house links, invoices, payments, wallet balance, WhatsApp opt-ins, documents and notes. A wallet is the credit that a resident pays in advance.
- You choose the email address and the phone numbers to keep, one field at a time. The merge stops with a clear message if both records are linked to the same house or both have a login.
- To confirm, you type the resident code of the record to keep.

### WhatsApp admin mode

- An admin can pin their own phone number to their account. The admin makes a one-time link code on the dashboard and sends it from the phone. Only roles with the new WhatsApp admin permission, and with two-factor login on, can do this.
- Each admin action in WhatsApp needs a code from the authenticator app. One approval opens a 15-minute session for lookups. A PDF always needs a new code.
- After five wrong codes, admin mode locks for that number for 30 minutes. Each admin can make 50 lookups a day. The system sends the admin an email after each lock and each new pin.
- An admin can send the house code or a name to see what a house owes. The reply shows the same amount as the "What I owe" answer to residents, with the debt status.
- An admin can ask for a debt status PDF for the whole estate or for chosen streets. The PDF lists each house with its debt status. It has no amounts and no resident names. The report goes to the admin by email.

### Settings

- A new **Two-factor login** page in **Settings** lets an admin set up an authenticator app, see backup codes once, and turn two-factor login off with a new code.

### Reports

- The indebtedness report and the indebtedness ranking now show the debt status for each house.

## Changes

- House and resident screens now use the same four debt status words: Outstanding, Arrears, Paid in Full and Credit. A house no longer shows "Clear" on one screen and a debt word on another.
- Two-factor login is now checked in the database. A session that skipped the second step cannot use admin data. This includes the files in the documents store. Failed code tries are counted exactly, so fast repeated guesses cannot pass the limit of five.
- The **Current Administrators** list on the **Settings > Roles & Access** page now shows columns for administrator, role, resident portal and actions.
- The performance of admin pages is now measured. The system keeps these measurements for 30 days. Only super admins can read them.

## Fixed problems

- **Deleted payments:** When you deleted a payment, the invoice stayed paid and the wallet kept the credit. The delete now reverses both. It stops if the resident has already spent the credit.
- **Duplicate payment check:** The check that stops one deposit being booked twice did not work for amount and date matches. It now works, and it shows errors.
- **Invoice corrections:** A credit note did not reduce the invoice that it corrected. That invoice now shows as paid or partly paid, so it no longer draws late fees and reminders.
- **Generate invoices:** The run failed for each resident with an empty wallet when the wallet option was on. It now creates the invoices.
- **Announcements:** The **Publish** button did not send the WhatsApp messages. It now sends them.
- **Scheduled reports:** Scheduled report emails were never sent. They now go out.
- **WhatsApp:** A resident's STOP message now works for shared phone numbers. It also works when an admin has recently typed on the handset.
- **Message queue:** Two overlapping runs could send one message twice. A message that stayed in "processing" for more than 30 minutes is now sent again.
- **Gmail connection:** The link that connects the estate Gmail account is now tied to the admin who started it.
- **Settings menu:** The settings menu column now scrolls and shows a scroll bar.

## Behind the scenes

- The agent instructions now include the board status issue in the start and end of each session.
