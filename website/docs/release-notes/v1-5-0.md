# Release v1.5.0

**Release date:** 16 October 2026. **Release type:** Minor (new features, no upgrade steps).

## Summary

Super-admins can now open an **Action Log** page that shows every scheduled job run and webhook delivery. The person who made an approval request now gets a notification when the request is approved or rejected. Long values on stat cards now fit inside the card.

## New features

### Administration

- The new **Action Log** page is in the **System** menu. It shows each scheduled job run and each verified webhook delivery that changed data or failed. Webhooks are the messages that WhatsApp and payment providers send to the app.
- Only users with the permission to view the system log can open the page. Only super-admins have this permission at first.
- You can filter the list by source, outcome and date range. The newest entries show first.
- The page shows rows only after the scheduled jobs run on the deployed version.

### Approvals

- The person who made an approval request now gets an in-app notification when the request is approved or rejected. The notification for a rejection includes the notes of the approver.

## Fixed problems

- Long values on stat cards, for example the **Total Collected** total on the **Payments** page, now get smaller to fit the card. Before, they went past the edge. Short values keep their size. This applies to the stat cards on all admin pages.
- The First Bank email alert reader no longer uses the current time as the transaction date when it cannot read the date. It now reads dates that include a time, and it reads the date when the header is split across two lines.

## Behind the scenes

- The role access check scripts no longer report "no difference" when the folder path has a space in it.
- The audit test list now records one email import step as a permanent exception, with the reason.
