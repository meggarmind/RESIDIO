# Release v1.4.0

**Release date:** 16 October 2026. **Release type:** Minor (new features). Operator steps are necessary: see **Before you upgrade**.

## Summary

You can now open an import from the **Import History** list and delete imports that did not finish. Only approved imports can now be processed. The dashboard loads faster, and visitor vehicles have stricter plate and primary vehicle rules.

## Before you upgrade

1. Apply two database changes to Residio_Prod before the deploy. The dashboard invoice cards fail without the first one.
2. Before you apply the vehicle change, check for duplicate active plates and for contacts with more than one active primary vehicle. The change stops if it finds either, and it changes no rows. Fix those records first.

## New features

### Payments and imports

- A row in **Import History** now opens the import when you click it.
- You can delete an import that is pending, failed or rejected. Use the row menu in **Import History** or the button on the import page. A confirmation dialog opens first. You need the permission to create imports.
- An import that did not finish uploading now has a **Delete** button, so it is no longer stuck.

### Security and access

- A visitor vehicle plate must now be unique among active vehicles. The app compares plates as upper-case letters and numbers only.
- A contact can have only one active primary vehicle. The app sets a new primary vehicle in one step.
- Check-in can now save a vehicle that belongs to the contact.

## Changes

### Payments and imports

- Only approved imports can be processed. You can no longer process an import straight from the review step. Submit it for approval first.
- The import wizard now loads the auto-tag rules one time for each import, not one time for each row.

### Dashboard

- The invoice distribution and monthly invoice count cards load faster.
- If the monthly invoice count cannot load, the trends section now shows no data. Before, it showed 0 invoices.

### Security and access

- The app now writes vehicle plates typed with hyphens in the same form when you create, update or search.

## Fixed problems

- The breadcrumb on the import page no longer reads "Details Details". It now reads "Import Details".
- Stored statement dates on the email import detail page and in the report templates now show the correct calendar day for viewers west of UTC. Nothing changes for Nigeria.

## Behind the scenes

- The release adds a check that compares the live access policies with a saved baseline.
- The release also adds a faster permission check on each page, and documentation updates.
