# Release v0.5.0

**Release date:** 11 October 2026. **Release type:** Minor (new features). Operator steps are necessary: see **Before you upgrade**.

## Summary

This release adds two switches that control the resident portal links in the admin dashboard. The links are now hidden by default. A super admin with no linked resident no longer sees a "Resident Portal" link that leads nowhere.

## Before you upgrade

1. Apply the new database migration `20261011140000_resident_portal_visibility_switches` to the production database.
2. Do this right after the merge and before the production deploy.

If you deploy first, the app is still safe. It keeps the links hidden until the migration is applied.

## New features

### Settings

- An estate-wide switch for the resident portal links is on **Settings > Estate Information**. The switch is off by default, so the links are hidden.

### Administration

- Each account has its own portal link setting on **System > Accounts**. The setting can be *Enabled*, *Disabled*, or *Inherit*. *Inherit* uses the estate-wide switch.
- A user cannot change their own portal link setting.

## Changes

- The links "My Portal" and "Resident Portal" show only when the account has a linked resident.
- The link "View as Resident" shows only when the user has the permission to view as a resident.
- Routing to `/portal` and the login redirects did not change.

## Fixed problems

### Administration

- Super admins with no linked resident no longer see the "Resident Portal" link.

## Behind the scenes

- The database types now include the new account setting.
