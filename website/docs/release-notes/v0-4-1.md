# Release v0.4.1

**Release date:** 11 October 2026. **Release type:** Patch (fixes only).

## Summary

This is the first release with a version number. From now on, each release to production gets a number, such as v0.4.1. This release also closes a security gap: a signed-in user could change some fields of their own profile, such as their role.

## Fixed problems

### Security and access

- A signed-in user can now change only the two theme settings of their own profile. Before this release, a user could change other fields, such as their role, through the database interface.
- Other profile changes still work as before. The app makes them with its own service access, so you do not need to do anything.

## Behind the scenes

- This release added the release process: a check that every change must pass, and automatic version numbers for releases to production.
- The release team now tests changes on the stage system first. Then they move the tested version to production.
