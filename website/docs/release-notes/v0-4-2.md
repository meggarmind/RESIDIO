# Release v0.4.2

**Release date:** 11 October 2026. **Release type:** Patch (fixes only).

## Summary

This hotfix corrects a fault in the health check of the app container. The fault stopped the first deploy to production. The app has no new features in this release.

## Fixed problems

### Administration

- The health check of the app container now judges the container by its own reply. Before this release, the check followed a redirect to the public web address. On a first deploy, that address was not ready, so the check failed and the deploy rolled back.
