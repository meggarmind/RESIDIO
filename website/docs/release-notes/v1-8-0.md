# Release v1.8.0

**Release date:** 19 October 2026. **Release type:** Minor (new features, no upgrade steps).

## Summary

The dashboard home is now a command board with three lanes and an estate map. Documents have tags, custom fields and better search. Lists show stacked cards on phones. Imports have stronger controls, and several settings and statement problems are fixed.

## New features

### Dashboard

- The dashboard home has a top strip with the most urgent item. Three lanes follow: Money, People and Houses, and Security and Access. Each lane has one headline figure, a status line, three queue rows and one main button.
- An estate map shows one cell for each active house, grouped by street. The color shows if the house is paid up. You can filter the map by status.
- Recent activity now shows payments, residents and security contacts only. The Action Needed tile and the separate Suggestions card are removed.
- The Collection and Verified figures now show their real periods (all time and this month). A figure of zero shows a neutral state, not a green arrow.
- Quick actions show only for users who have the matching write permission.

### Documents

- Documents have tags and custom fields. A new settings page lets you create, nest, edit and deactivate tags and custom fields.
- The **Documents** page has a tag filter and tag chips. The upload form has a tag picker. The document detail page has a **Tags & Fields** card.
- Document search now searches the title, the description and the file name. It ranks title matches first.

### Imports

- A super admin can reset a failed bank statement import. The **Reset** button is on the import detail page. It shows how many rows the import already created. Approval then starts again.
- Email imports have an approval limit. A credit above the limit waits for approval and does not create a paid payment. The queue marks these items "Needs approval". Only users with approval permission can release them.
- A super admin sets the limit in the **Auto-process limit (NGN)** field on the email integration settings page. The default is 60,000 naira.
- After you submit an import for approval, you cannot edit its rows. An import is also claimed before it posts, so two runs cannot post the same import twice.

### Security and access

- Security contacts have a vehicles card. You can list, add, edit, set as primary and remove vehicles. **Record Check-In** has a vehicle picker.
- Visitor analytics is now on the security pages. It is read-only.
- You can clear a flag on an access log entry. You can also make a new access code for a contact.

### Settings

- Number settings, such as the late fee grace period, save only when you save. Before, they saved on each key press and replaced an empty or invalid value with a default.
- Actions that charge residents, lock users out, send real messages or delete data now ask for confirmation. Many of them first show a preview of what the action affects.
- On the WhatsApp settings page, you choose pilot residents by name from a searchable list. You no longer paste resident IDs.

### Phone layouts

- Below 768 pixels wide, the lists for residents, houses, payments, invoices, approvals and security contacts show stacked cards instead of table rows. A **Sort by** control replaces the table headers.
- Icon-only buttons are 44 pixels square on phones. Icon-only buttons have names for screen readers.
- Small text is now at least 12 pixels high.

## Changes

- The dashboard financial totals, payment totals, invoice aging, resident verification counts and the financial overview report are now added up in the database. Before, totals could be wrong above 1,000 rows.
- Matching of import rows is faster. The number of database queries no longer grows with the number of rows.
- The **Data Retention** page now also deletes system action log entries older than 90 days.
- Status colors now follow the theme. Paid and success show green in every theme. Status labels are easier to read.

## Fixed problems

- **Account statement:** The statement loaded with an error each time. It now loads. Legacy dues are shown in the correct period, and payments are counted once.
- **PDF reports:** PDFs printed a broken naira sign. They now print "NGN" before the amount. This applies to the statement, the receipt and four report PDFs.
- **Maintenance mode:** Maintenance mode did not lock out users when you turned it on in settings. It now does.
- **Prune Data:** **Prune Data** and its preview failed each time for notifications. They now work.
- **Late fees:** **Apply Late Fees Now** failed on a missing field. It now works.
- **Security contacts:** The filter row no longer goes past the screen edge on phones. The filter rows also wrap at tablet widths, so the table is not cut off.
- **Residents' own records:** A signed-in resident could change admin-controlled fields on their own record. This is no longer possible. Residents can change only their contact details.
- **Approvals:** Any signed-in user could reject all expired pending approvals. Only the system can now do this.
- **WhatsApp:** The assistant now records each financial answer in the disclosure log before it sends the reply. Chatmaid now pauses the bot only for messages that an admin types by hand, not for the bot's own replies.

## Behind the scenes

- Dependencies were updated, including security updates.
- Unused theme code was removed. Design guidance documents were added for the admin dashboard.
