# Release v1.6.0

**Release date:** 16 October 2026. **Release type:** Minor (new features). Operator steps are necessary: see **Before you upgrade**.

## Summary

Approval requests that you create from now on expire after 72 hours. The app rejects them by itself and tells the requester. An import with no matched rows can no longer be submitted for approval.

## Before you upgrade

1. In Coolify, create a scheduled task for the route `/api/cron/expire-approvals`. Set it to run every hour (`0 * * * *`).
2. Create the task on residio-prod only. Residio-stage runs no scheduled tasks.
3. Until you create the task, no request expires.

## New features

### Approvals

- A pending approval request now expires after 72 hours. The app rejects it and sends the requester an in-app notification with the title "Request expired".
- Requests that were already pending before this release never expire.
- The System Action Log records each run of the expiry job.

## Changes

### Payments and imports

- You can no longer submit an import for approval if it has no matched rows. The import detail page turns off the **Submit** button and shows the same message as the import wizard. An import with some unmatched rows and at least one matched row is still allowed.

## Behind the scenes

- The `finish` step of the issue workflow tool now opens the pull request and stops. It no longer merges.
